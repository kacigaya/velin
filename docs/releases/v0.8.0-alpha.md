Preview release of Velin, a native Android mail client for Tuta. This version sends files. Do not use it as your main mail app yet.

## New

- Attach files to a mail. Tap the paperclip in the composer and pick one or more files. All files of one mail can be up to 25 MB together.
- A forward keeps the files of the original mail.
- Files are end-to-end encrypted before upload, like the mail itself. Velin sends confidential mail with files to Tuta addresses.
- Drafts keep their files. You can remove a file from a draft, except while it uploads.

## Known limits

- Sending files has not been checked against a live Tuta account yet. If a file does not open for the recipient, please open an issue.
- Images inside the quoted text of a forward are attached as ordinary files.
- Velin can still send only to Tuta addresses. Scheduled send is not available yet.
- The other known limits of [v0.7.0-alpha](https://github.com/kacigaya/velin/releases/tag/v0.7.0-alpha) still apply.

## Update from v0.7.0-alpha

Install the new APK over the old one. Both use the same signing key, so your saved account and saved mail stay.

## Verify the download

Compare the SHA-256 checksum of the APK with `SHA256SUMS`.
