Third preview of Velin, a native Android mail client for Tuta. Velin now keeps your mail on the device, so you can read it without a network. Do not use it as your main mail app yet.

## New

- Velin opens without a network. It shows your folders, the mail lists you loaded and the mails you opened before. A banner tells you that Velin is offline.
- Changes made in another Tuta app reach Velin. If Velin was offline or closed, it gets the missed changes when it connects again. Moved, read and deleted mail updates without a manual refresh.
- New mail shows in the open folder. A new reply shows in the open conversation.
- Saved mail is encrypted with a key that stays in the Android Keystore. Signing out deletes it.

## Fixed

- A mail that was deleted on the server now shows "not found" instead of a general error.

## Not yet available

- Sending to addresses outside Tuta, with or without a password.
- Attachments in new mail, reply, forward and scheduled sending.
- Search, notifications and contact suggestions.
- Checking a recipient's key fingerprint by hand. If a key changed, the only fix now is to remove that recipient.
- Sign-in with a security key.

## Known limits

- Velin keeps 200 mails per folder and the last 100 mails you opened. A mail you never opened cannot open offline.
- Before the first change arrives from the server, Velin reloads the open folders each time it connects.
- Velin keeps its own list of trusted recipient keys. Keys you verified in the official Tuta app do not carry over.
- Velin cannot yet verify sender signatures on received mail. Velin never shows a mail as verified.
- The pinned Tuta SDK includes the Rust `rsa` crate 0.9.8, which has a timing side-channel advisory without a fixed version ([RUSTSEC-2023-0071](https://rustsec.org/advisories/RUSTSEC-2023-0071.html)). The official Tuta app uses the same version.
- The APK supports 64-bit ARM and x86 devices only.

## Update from v0.2.0-alpha

Install the new APK over the old one. Both use the same signing key, so your saved account stays.

## Verify the download

Compare the SHA-256 checksum of the APK with `SHA256SUMS`.
