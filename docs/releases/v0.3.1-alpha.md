Patch release of Velin, a native Android mail client for Tuta. It fixes one bug in v0.3.0-alpha. Do not use it as your main mail app yet.

## Fixed

- The folder menu and mail taps stopped working when you picked a folder before the folder menu was fully open. Velin now stays usable after fast taps.

## Not yet available

- Reply and forward.
- Sending to addresses outside Tuta, with or without a password.
- Attachments in new mail and scheduled sending.
- Search, notifications and contact suggestions.
- Checking a recipient's key fingerprint by hand. If a key changed, the only fix now is to remove that recipient.
- Sign-in with a security key.

## Known limits

The known limits of [v0.3.0-alpha](https://github.com/kacigaya/velin/releases/tag/v0.3.0-alpha) still apply.

## Update from v0.3.0-alpha

Install the new APK over the old one. Both use the same signing key, so your saved account and saved mail stay.

## Verify the download

Compare the SHA-256 checksum of the APK with `SHA256SUMS`.
