Preview release of Velin, a native Android mail client for Tuta. This version makes mail easier to scan and adds a working settings screen. Do not use it as your main mail app yet.

## New

- Unread mail uses tonal groups. Subjects can use two lines. Labels use neutral colors in the mail list.
- The folder name is easier to read. The compose button is smaller and uses the theme accent.
- Account details stay in the folder drawer. The search bar has no profile button, and the drawer has no app-name header.
- Settings shows a compact account card and grouped rows. Appearance, contrast, and accessibility open Android system settings.
- Sign out from settings after confirmation. Remote images remain blocked by default, with consent for each message.

## Fixed

- The theme updates when you change system contrast without restarting the screen.

## Known limits

- Settings uses Android controls. It does not add separate app theme or contrast preferences.
- The filter button from the design mock is not included. Search and filtering are not available yet.
- Other feature and security limits from [v0.5.0-alpha](https://github.com/kacigaya/velin/releases/tag/v0.5.0-alpha) still apply.
- The APK supports 64-bit ARM and x86 devices only.

## Update from v0.5.0-alpha

Install the new APK over the old one. The signing key stays the same, so your saved account and mail stay.

## Verify the download

Compare the SHA-256 checksum of the APK with `SHA256SUMS`.
