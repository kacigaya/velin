Second preview of Velin, a native Android mail client for Tuta. You can now act on mail, keep drafts and send encrypted mail to Tuta addresses. Do not use it as your main mail app yet.

## New

- Mark mail as read or unread. Opening a mail marks it as read.
- Archive, move to Trash or Spam, and move to any folder. A move shows a message with an undo action. Moving to Spam does not send a spam report to Tuta yet.
- Delete mail permanently from Trash and Spam, after a confirmation. This is not yet tested against the server.
- Add and remove labels, on one mail or on many.
- Select several mails with a long press.
- Write mail. Drafts save automatically. Open a draft again with **Edit draft**. Discarding a draft moves it to Trash.
- Send end-to-end encrypted mail to Tuta addresses. Velin checks the address of each recipient and their encryption key. If a key changed, Velin blocks the send and marks the recipient.
- Velin opens your saved account at start when you have only one.

## Fixed

- Error messages now show over the composer and over a mail on phones.
- On tablets, the mail text is no longer cut off.
- Screen readers now name the Compose and Account buttons.

## Not yet available

- Sending to addresses outside Tuta, with or without a password.
- Attachments in new mail, reply, forward and scheduled sending.
- Search, notifications, offline mode and contact suggestions.
- Checking a recipient's key fingerprint by hand. If a key changed, the only fix now is to remove that recipient.
- Sign-in with a security key.

## Known limits

- Velin keeps its own list of trusted recipient keys. Keys you verified in the official Tuta app do not carry over.
- Velin cannot yet verify sender signatures on received mail. Velin never shows a mail as verified.
- The pinned Tuta SDK includes the Rust `rsa` crate 0.9.8, which has a timing side-channel advisory without a fixed version ([RUSTSEC-2023-0071](https://rustsec.org/advisories/RUSTSEC-2023-0071.html)). The official Tuta app uses the same version.
- The APK supports 64-bit ARM and x86 devices only.

## Update from v0.1.0-alpha

Install the new APK over the old one. Both use the same signing key, so your saved account stays.

## Verify the download

Compare the SHA-256 checksum of the APK with `SHA256SUMS`.
