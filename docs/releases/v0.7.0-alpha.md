Preview release of Velin, a native Android mail client for Tuta. This version gives the app a new typeface. Do not use it as your main mail app yet.

## New

- All text in the app uses Google Sans Flex, a rounded variable typeface. The app includes the font, so it looks the same on all devices.
- Velin has a download website at https://kacigaya.github.io/velin/. It always links to the newest APK.

## Known limits

- The APK is about 4 MB larger, because it includes the font.
- The known limits of [v0.6.0-alpha](https://github.com/kacigaya/velin/releases/tag/v0.6.0-alpha) still apply.

## Update from v0.6.1-alpha

Install the new APK over the old one. Both use the same signing key, so your saved account and saved mail stay.

## Verify the download

Compare the SHA-256 checksum of the APK with `SHA256SUMS`.
